# Algorithms and Puzzles — C++ Solutions

This repository contains my personal solutions for different years of **Advent of Code** and assorted **LeetCode** challenges.

The project is primarily a learning exercise. I am using these puzzles to practice:

- Modern C++;
- Problem decomposition;
- Parsing structured input;
- Algorithms and data structures;
- Testing and debugging;
- Analysing time and space complexity;
- Organising small C++ programs with separate interfaces and implementations.

These are exploratory solutions rather than attempts to produce the shortest or most competitive implementations. Some solutions may be revised as I discover cleaner algorithms or improve my C++ design.

*Note: In accordance with Advent of Code community guidelines, puzzle input files (`input.txt`) are kept locally and are not committed to the remote repository.*
